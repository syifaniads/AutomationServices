## Portfolio treatment

This repository is hosted under Syifani's GitHub account and is maintained as portfolio evidence. That does **not** mean every source file, deployment artifact, design decision, or commit was produced by one person.

The retained GitHub history includes commits associated with teammate identities, and historical project branches contain shared artifacts. This is normal for a collaborative project and is intentionally preserved rather than rewritten.

## What this portfolio claims

The safe interpretation is:

> Participated in a three-person project that built a room-booking web application and explored an automated Jenkins -> Docker Hub -> AWS EC2 delivery pipeline, with retained GitHub evidence for the application, Jenkins configuration, container build, deployment script, and UI validation artifacts.

## What this portfolio does not claim

It does not claim that Syifani individually authored:

- every application feature;
- every line in the Jenkinsfile;
- all Docker configuration;
- all historical commits;
- all AWS setup;
- any unavailable GitLab-only work.

## Shared-device / repository history

Author identity in Git is useful evidence, but collaborative coursework can involve shared machines, teammate branches, and code integration. This portfolio therefore relies on multiple evidence types:

- team proposal;
- repository history;
- retained feature branches;
- application source;
- documentation and screenshots.

If the original institutional GitLab becomes accessible, its contribution history can be added as another source without replacing the attribution rules above.
